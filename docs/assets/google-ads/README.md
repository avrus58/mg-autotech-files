# Google Ads creative review pack

Prepared for the paused UK/Ireland Search campaign. Nothing in this directory
is uploaded or associated with a live campaign automatically.

## Business information

- `mg-autotech-business-logo-1200.png`: 1200 x 1200 PNG rendered from the
  repository-owned `public/mg-autotech-logo.svg`. Intended only for the Google
  Ads business-logo slot, not as a Search image asset.

## Search image candidates

All four candidates are PNG files below Google's 5,120 KB limit. They have no
added logo, text overlay or watermark and keep the important subject inside the
central safe area.

| File | Dimensions | Intended ratio |
| --- | ---: | --- |
| `ecu-tcu-workbench-square.png` | 1254 x 1254 | 1:1 |
| `secure-ecu-file-review-square.png` | 1254 x 1254 | 1:1 |
| `ecu-diagnostic-workbench-landscape.png` | 1734 x 907 | 1.91:1 |
| `workshop-ecu-connection-landscape.png` | 1734 x 907 | 1.91:1 |

The images were generated with the built-in OpenAI image-generation workflow
on 2026-08-28 from four separate prompts. Each prompt requested credible ECU or
TCU workshop/file-review photography, dark graphite with restrained red
lighting, no manufacturer branding, no readable text, no emissions-delete
symbolism and no exaggerated performance imagery. The owner must review the
final pixels and confirm the right to use and share them commercially before
uploading them to Google Ads. They must be identified as AI-generated in the
Google Ads upload flow wherever Google offers or requires that disclosure.

## Live-operation boundary

Before upload, confirm the exact campaign association and retain the campaign
in `Paused` state. Uploading or saving assets is a live Google Ads account edit
and requires an action-time owner confirmation. Google policy review and asset
eligibility remain external outcomes; local file validation cannot guarantee
approval or serving.
