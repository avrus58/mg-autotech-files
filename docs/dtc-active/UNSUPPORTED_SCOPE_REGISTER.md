# DTC Active Unsupported Scope Register

The following remain unsupported in Phase A:

- real ECU DTC OFF;
- real ME7.5 rules;
- real EDC15 rules;
- real EDC16 rules;
- any customer-provided offsets, scripts or byte values;
- guessed checksum correction;
- signature or secure-boot bypass;
- automatic emissions/regulatory category modification;
- safety-critical modification;
- security-related modification;
- powertrain protection modification;
- unknown-risk modification;
- A3 production processing;
- A4/A5 automation;
- customer delivery or publication.

Reason: no authorized exact MG rule bundle, adapter qualification, local migration verification, worker isolation or customer publication gate exists yet.
