# Deterministic Insights

The first insight engine is deterministic and does not use an LLM.

Implemented categories include:

- review backlog
- authorization gap
- identity extraction gap
- multi-service evidence needing clean single-service pairs
- approved evidence without pattern support
- map definitions without approved pairs
- DTC evidence missing exact code labels
- promising research candidate with remaining blockers
- backfill opportunity

Insights never approve samples, create rules, modify firmware or change readiness automatically.
