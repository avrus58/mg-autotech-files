# ECU Intelligence Metrics

Overview metrics are duplicate-safe where hashes are available:

- upload candidates
- exact identity clusters
- distinct source SHA-256 count
- ORI/MOD pair candidates
- reviewed pairs
- approved learning pairs
- single-service pairs
- multi-service pairs
- checksum-only/no-op controls
- human verified samples
- approved training samples
- pattern and map coverage
- review queue count
- unresolved authorization and identity conflict counts

Synthetic/demo evidence is excluded from real metrics by default.
