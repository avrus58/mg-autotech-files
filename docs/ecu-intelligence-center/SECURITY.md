# ECU Intelligence Security

The ECU Intelligence Center is staff-only and requires `ai_training.manage`.

Rules:

- no anonymous access
- no ordinary customer access
- no service-role key in browser code
- no raw firmware bytes
- no storage paths
- no signed URLs
- no customer PII
- no payment data
- no internal customer notes
- no customer-facing API

All views are admin evidence projections over existing private systems.
