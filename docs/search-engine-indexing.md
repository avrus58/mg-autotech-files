# Search Engine Indexing Operations

## Purpose

MG AutoTech publishes one canonical public sitemap at:

- `https://file.mgautotech.de/sitemap.xml`

Google discovery already uses Search Console. This layer extends technical
discovery to Bing and IndexNow participants, while preparing optional ownership
verification for Yandex, Baidu and Naver. Search engines decide whether and when
to crawl or index a URL; submission does not guarantee ranking or inclusion.

## Public discovery boundary

Only URLs generated by `src/app/sitemap.ts` can be submitted. The IndexNow
helper validates every URL again before network access. It requires:

- HTTPS;
- exact host `file.mgautotech.de`;
- no query string, fragment, credentials or alternate port;
- no admin, API, auth, dashboard, payment, registration or customer route.

The public IndexNow ownership key is stored at:

- `public/53478ab4be7faddc91a14935b2b35013051e4dfc9bb31c4a.txt`

IndexNow keys are public ownership-verification material, not application
secrets. No customer, order, payment, file or account data is submitted.

## Commands

Validate the canonical URL set without making a network request:

```powershell
npm run seo:indexnow:check
```

After the matching application release is live, an authorized admin can use
the **Notify search engines** action in `/admin/seo-performance`. The equivalent
explicit operator command is:

```powershell
npm run seo:indexnow:submit
```

The submit command is never run by build or deployment scripts.

## Webmaster ownership configuration

Optional server-side environment variables add standard ownership meta tags.
They contain public verification tokens and must contain only the exact value
issued by the relevant webmaster console:

- `BING_SITE_VERIFICATION`
- `YANDEX_SITE_VERIFICATION`
- `BAIDU_SITE_VERIFICATION`
- `NAVER_SITE_VERIFICATION`

Malformed or missing values are ignored. Never place account passwords, API
keys, service-role credentials or webmaster session cookies in these values.

### Bing Webmaster Tools

1. Add `https://file.mgautotech.de` or import the already verified property from
   Google Search Console.
2. Submit `https://file.mgautotech.de/sitemap.xml`.
3. If Bing issues a meta verification token, set `BING_SITE_VERIFICATION` for
   the Production environment and release the application.
4. Use URL Inspection and Site Explorer after Bing has processed the sitemap.

Bing recommends IndexNow for changed URL discovery. A successful IndexNow
response confirms receipt, not indexing or ranking.

### Yandex Webmaster

1. Add the exact HTTPS host `https://file.mgautotech.de`.
2. Set the issued token as `YANDEX_SITE_VERIFICATION` and release.
3. Submit `https://file.mgautotech.de/sitemap.xml` in Yandex Webmaster.
4. Monitor sitemap processing and excluded-page reasons. Processing can take
   time and should not be treated as an immediate ranking signal.

### Baidu and Naver

These are optional regional channels. Add each exact HTTPS site in its official
webmaster console, set only the issued verification token, submit the same
sitemap and monitor crawl results. Do not create duplicate regional pages or
doorway pages merely to increase index count.

## Release verification

After release, verify:

1. `/robots.txt` returns `200` and references the canonical sitemap.
2. `/sitemap.xml` returns `200` and contains no private routes.
3. The IndexNow key URL returns the exact key as plain text.
4. Public HTML has the configured verification meta tags and no token is
   rendered when its configuration is absent or invalid.
5. The admin notification action returns an accepted URL count.
6. Bing and Yandex webmaster consoles show sitemap receipt after their normal
   processing delay.

## Troubleshooting

- `401` or `403` from the admin notification route means the session lacks the
  required staff permission.
- `429` means the bounded notification limit was reached; wait before retrying.
- `502` means IndexNow could not be reached or rejected the request. No private
  URL is sent in this failure path.
- A webmaster console can report a discovered URL as not indexed. Inspect the
  canonical, content quality and crawl reason; do not repeatedly submit it.
